## English

**Changed**
- Versions 1.1.5 and older cannot update themselves. Their updater window now tells you to download the latest release from GitHub and, during installation, to uninstall the old version and clean the app data. It links to the GitHub repository.

**Fixed**
- With screens stacked one above the other, windows now open on the screen you are working on instead of the one below it.

## 中文

**变更**
- 1.1.5 及更早的版本无法自动更新。它们的更新窗口现在会提示从 GitHub 下载最新版本，并在安装时选择卸载旧版本并清理应用数据，窗口中附有 GitHub 仓库的链接。

**修复**
- 屏幕上下排列时，窗口现在会在当前使用的屏幕上打开，而不是出现在下方的屏幕上。

## 한국어

**변경**
- 1.1.5 이하 버전은 자동으로 업데이트할 수 없습니다. 이 버전의 업데이트 창이 이제 GitHub에서 최신 릴리스를 내려받고, 설치할 때 이전 버전을 제거하고 앱 데이터를 삭제하도록 안내하며, GitHub 저장소 링크를 보여 줍니다.

**수정**
- 화면이 위아래로 배치된 경우, 창이 아래 화면이 아니라 현재 작업 중인 화면에서 열립니다.
