## English

**Changed**
- When a web language detection engine fails, the language label in the Translate window now says "Detection failed (English)", so you know English is only the fallback. Without a network, the text is still translated instead of nothing happening.

**Fixed**
- Claude Code and Codex no longer leave an empty reply when a turn ends without an answer: the card shows the reason, with the retry button.

## 中文

**变更**
- 在线语种检测引擎检测失败时，翻译窗口的语言标签会显示“检测失败（英语）”，让你知道此时是按默认的英语处理的。没有网络时也会照常翻译，而不是毫无反应。

**修复**
- Claude Code 和 Codex 在一轮对话没有给出回答时不再留下空白结果：卡片会显示原因，并带有重试按钮。

## 한국어

**변경**
- 온라인 언어 식별 엔진이 실패하면 번역 창의 언어 표시에 "감지 실패(영어)"라고 나타나, 영어가 기본값으로 쓰였음을 알 수 있습니다. 네트워크가 없어도 아무 반응이 없는 대신 번역이 진행됩니다.

**수정**
- Claude Code와 Codex가 답 없이 끝났을 때 더 이상 빈 결과를 남기지 않습니다. 카드에 이유가 표시되고 다시 시도 버튼이 나타납니다.
