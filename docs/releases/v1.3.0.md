## English

**New**
- Translation results can replace the selected text: each result has a Replace button that puts its translation where the text you selected was, as writing improvement does with a rewrite.

**Fixed**
- Selection translation no longer sometimes gets no text in Chrome, which you could only fix by selecting the text again. The shortcut now waits until you let go of its keys before copying the selection.
- Writing improvement now replaces the selected text in Chrome, for example in Gmail, where the result was not pasted back.

## 中文

**新增**
- 翻译结果可以替换选中的文字：每条结果都有“替换”按钮，点击后译文会替换原先选中的文字，与写作润色替换润色结果的方式相同。

**修复**
- 修复 Chrome 中划词翻译有时取不到文字、必须重新选中才行的问题。现在快捷键会等你松开按键后再复制选中的文字。
- 修复写作润色在 Chrome 中（例如 Gmail）无法把结果替换回原文的问题。

## 한국어

**새 기능**
- 번역 결과로 선택한 글을 바꿀 수 있습니다. 결과마다 있는 바꾸기 버튼을 누르면 글쓰기 개선의 결과처럼 선택했던 글이 그 번역으로 바뀝니다.

**수정**
- Chrome에서 선택 번역이 가끔 글을 가져오지 못해 다시 선택해야 하던 문제를 고쳤습니다. 이제 단축키에서 손을 뗀 뒤에 선택한 글을 복사합니다.
- Chrome(예: Gmail)에서 글쓰기 개선 결과가 원래 자리에 붙여 넣어지지 않던 문제를 고쳤습니다.
