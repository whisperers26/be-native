## English

**New**
- Two more read-aloud services: Google and Youdao. Both need no key, and Youdao works from mainland China.
- A System voice service that reads aloud with the voices installed on your computer, offline. Windows, macOS and Linux (`espeak-ng`) are supported. Windows and macOS need a voice for the language installed.

**Fixed**
- The Read button works again. It used the Lingva service, whose default server no longer exists, and showed a network error. Read now uses Google by default, and your existing Lingva setting is moved to Google once at launch.

## 中文

**新增**
- 新增两个朗读服务：Google 和有道。两者都无需密钥，有道可在中国大陆使用。
- 新增“系统语音”服务，使用电脑上已安装的语音离线朗读。支持 Windows、macOS 和 Linux（`espeak-ng`）。Windows 和 macOS 需要安装对应语言的语音。

**修复**
- 修复“朗读”按钮无法使用的问题。它此前使用的 Lingva 服务的默认服务器已不存在，会显示网络错误。现在默认使用 Google 朗读，并且在启动时会把原有的 Lingva 设置一次性改为 Google。

## 한국어

**새 기능**
- 읽기 서비스 두 가지를 추가했습니다: Google과 Youdao. 둘 다 키가 필요 없으며, Youdao는 중국 본토에서도 사용할 수 있습니다.
- 컴퓨터에 설치된 음성으로 오프라인에서 읽어 주는 시스템 음성 서비스를 추가했습니다. Windows, macOS, Linux(`espeak-ng`)를 지원하며, Windows와 macOS에서는 해당 언어의 음성이 설치되어 있어야 합니다.

**수정**
- 읽기 버튼이 다시 작동합니다. 이전에 사용하던 Lingva 서비스의 기본 서버가 없어져 네트워크 오류가 표시되었습니다. 이제 기본값은 Google이며, 기존 Lingva 설정은 실행할 때 한 번 Google로 바뀝니다.
