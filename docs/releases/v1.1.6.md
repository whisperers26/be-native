## English

**Changed**
- RapidOCR is now the default OCR service on a fresh install, so small text is read offline out of the box. An OCR service list you already saved is left as it is.
- The Recognize window closes when it loses focus by default, like the Translate window.
- Menus in the Config window open without the scale-and-fade animation, to stop the page behind a menu from flickering in front of it.

## 中文

**变更**
- 全新安装时，RapidOCR 成为默认的文字识别服务，开箱即可离线识别小字。已有的文字识别服务列表保持不变。
- 文字识别窗口默认在失去焦点时关闭，与翻译窗口一致。
- 设置窗口里的菜单不再有缩放淡入动画，避免菜单后面的页面闪烁到菜单前面。

## 한국어

**변경**
- 새로 설치하면 RapidOCR이 기본 OCR 서비스가 되어, 작은 글자도 바로 오프라인으로 인식합니다. 이미 설정한 OCR 서비스 목록은 그대로 유지됩니다.
- 문자 인식 창은 번역 창처럼 기본적으로 포커스를 잃으면 닫힙니다.
- 설정 창의 메뉴는 확대·페이드 애니메이션 없이 열려, 메뉴 뒤의 화면이 메뉴 앞으로 깜박이지 않습니다.
