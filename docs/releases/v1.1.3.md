## English

**New**
- Claude Code and Codex services: a button beside the model field asks the installed tool which models it offers and lists them, so you can pick one instead of typing its name. Codex had no list before. Asking uses none of your subscription.

## 中文

**新增**
- Claude Code 和 Codex 服务：模型输入框旁新增一个按钮，可向本机安装的工具查询当前提供的模型并列出，直接选择即可，无需手动输入名称。此前 Codex 没有模型列表。查询不会消耗订阅额度。
